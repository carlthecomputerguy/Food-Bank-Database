# I-70 Street Reach Food Bank Database - Client Installation

## Quick Start

1. **Run `install.bat`** - This will:
   - Configure the server URL to https://database.i70streetreach.com
   - Install required Python packages (requests, openpyxl, keyring)

2. **Double-click `Start Application.bat`** to launch the client

## Login Credentials

- **Username:** admin
- **Password:** Foodbank2025!

## For Administrators

Use the **"Manage Users"** button in the application to create accounts for your team members.

## System Requirements

- Windows 10 or later
- Python 3.8 or later
- Internet connection

## Troubleshooting

If the application doesn't start:
1. Make sure Python is installed from https://www.python.org/
2. Re-run `install.bat` to reinstall packages
3. Check your internet connection
4. Contact support if issues persist
